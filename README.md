# Zoom連携・ローカルLLM活用ダッシュボード

Zoomの文字起こしデータからタスクを抽出・管理し、議事録や週報を自動生成するダッシュボードWebアプリケーションです。バックエンドとして `llama.cpp` のOpenAI互換API（ローカルLLM）を利用します。

---

## 🛠 Windows 11 環境構築手順

本アプリケーションを Windows 11 環境で動かすためのセットアップ手順です。

### 1. 必須ソフトウェアのインストール

#### ① Node.js のインストール
フロントエンド（React/Vite）を動作させるために必要です。
1. [Node.js 公式サイト](https://nodejs.org/) から **LTS版（推奨版）** のインストーラーをダウンロードします。
2. ダウンロードしたインストーラーを実行し、標準設定のままインストールを完了させます。
3. PowerShellまたはコマンドプロンプトを開き、以下のコマンドでインストールされたか確認します。
   ```powershell
   node -v
   npm -v
   ```

#### ② llama.cpp のセットアップ（ローカルLLM）
タスク抽出や議事録要約の推論を行うために必要です。
1. [llama.cpp リリースページ](https://github.com/ggerganov/llama.cpp/releases) から、Windows用のコンパイル済みバイナリ（例: `llama-bXXXX-bin-win-vulkan-x64.zip` または `cuda` 版など、ご自身のGPU環境に合わせたもの）をダウンロードし、任意のフォルダに解凍します。
2. LLMのモデルファイル（GGUF形式）をダウンロードします。
   - 例: Hugging Face等から `Qwen` などのチャット対応モデル（`.gguf`）をダウンロードし、llama.cpp を解凍したフォルダ内に配置します。

---

### 2. アプリケーションのセットアップ

1. コマンドプロンプトまたは PowerShell を開き、本プロジェクトのフォルダに移動します。
   ```powershell
   cd パス\への\ディレクトリ\05_pj_dashboard
   ```

2. 依存パッケージをインストールします。
   ```powershell
   npm install
   ```

---

### 3. 起動手順

ダッシュボードを利用するには、**LLMサーバー** と **Webアプリ** の両方を起動しておく必要があります。

#### ① ローカルLLMサーバー (llama.cpp) の起動
解凍した `llama.cpp` のフォルダでコマンドプロンプトを開き、サーバーモード（OpenAI互換API）で起動します。
※ モデルファイル名やGPUのレイヤー数（`-ngl`）は環境に合わせて変更してください。

```powershell
# 例: llama-server.exe を使用し、ポート8080でCORSを許可して起動
llama-server.exe -m your_model.gguf -c 4096 -ngl 33 --host 0.0.0.0 --port 8080
```
> **注意:** Webアプリからアクセスするため、必ず同一PC上でポート `8080` 等を開放し、アクセスできる状態にしてください。

#### ② Webアプリケーションの起動
プロジェクトのディレクトリ（`05_pj_dashboard`）で以下のコマンドを実行します。

```powershell
npm run dev
```

起動後、ターミナルに表示されるURL（通常は `http://localhost:5173/` ）にブラウザでアクセスします。

---

### 4. アプリケーションの初期設定（ブラウザ上）

1. ブラウザでダッシュボードを開き、左メニューから **Settings（設定画面）** を開きます。
2. **LLM API エンドポイント**: `llama.cpp` サーバーのアドレス（例: `http://localhost:8080/v1`）が設定されていることを確認します。
3. **議事録/画像ディレクトリ**: Windows環境のパス（例: `C:\Users\username\Documents\ZoomMinutes`）に変更し、「保存」を押します。
   - ※ ViteのローカルAPIを利用しているため、このパスに配置された `議事録.txt` 等がバッチ処理の対象となります。

---

## 🚀 主な機能と使い方

- **一括自動処理 (Minutes画面)**
  - 指定したディレクトリに `.txt` 形式でZoomの文字起こし結果を配置します。
  - Minutes画面の「自動一括処理を実行」ボタンを押すと、LLMが要約とタスク抽出を行い、処理済みファイルは `_処理済み` とリネームされます。
- **タスクの通知と承認**
  - 自動抽出されたタスクは「新規タスク」として左下のベルアイコンに通知されます。
  - 担当者などを微修正し、「承認して追加」することで Kanban / Scheduler に反映されます。
- **Kanban / Scheduler (WBS)**
  - 承認されたタスクの進捗をドラッグ＆ドロップで管理できます。
- **週報作成 (Report画面)**
  - 過去7日間の議事録要約を基に、LLMが週報を自動生成します。
